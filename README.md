# Задание:

Предметная область: Управление задачами

Примерные сущности: Project, Task, User, Tag, Comment

Описание: Задача принадлежит проекту и назначается пользователю; теги помечают задачи. Комментарии привязаны к задачам; статусы задач меняются по допустимым переходам (например, OPEN - IN_PROGRES - DONE).

# Задание 4. Базовая безопасность API

Подключите SpringSecurity к своему проекту

Проведите базовую настройку, включив Basic Auth и настроив CSRF токены

Добавьте пользователей в свой проект, вводя отдельный класс или используя существующий

Настройте авторизацию в своём сервисе по ролям или разрешениям для каждой конечной точки вашего приложения

Добавьте процедуру регистрации

Сделайте проверку надёжности пароля при регистрации (например длина и наличие спецсимволов)

Подготовьте почву для аутентификации по логину и паролю (пока мы используем BasicAuth она нам отдельно не требуется, но в будущем понадобится)

Убедитесь, что все операции работают правильно и все доступы выдаются согласно настройкам
